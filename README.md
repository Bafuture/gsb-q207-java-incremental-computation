## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的派生数据由多个计算节点串联而成，每次源数据变化都全量重算代价太高。请从零实现一个增量计算引擎。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持定义计算节点（输入、依赖、计算函数）并构成有向无环图；2) 源数据变化时沿依赖链传播脏标记，只重算受影响的节点，需给出重算节点数与全量重算的对比；3) 支持合并重算：同一轮内多个上游变化时，下游只重算一次而不是多次；4) 检测循环依赖并报错并给出环路径；5) 支持取值缓存：无变化时返回值不触发计算，需统计缓存命中数；6) 支持并发重算：互不依赖的节点可以并行计算，需保证同一节点不被重复计算；7) 提供统计：节点总数、本轮重算数、缓存命中数与计算总耗时；8) 测试覆盖脏标记传播、合并重算、环检测、缓存命中、并发重算与统计；`mvn -q verify` 一条命令跑通。
